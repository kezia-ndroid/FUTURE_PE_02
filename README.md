## Ad Framework Used

All scripts follow the proven UGC structure:

```
HOOK (0–3s) → PROBLEM (3–12s) → SOLUTION (12–25s) → PROOF (25–30s) → CTA (last 5s)
```

This framework is used by top D2C brands and UGC creators because it:
- Mirrors how real customers talk about products
- Builds trust before selling
- Drives action without feeling like a traditional ad

## How to Reuse These Prompts

Every prompt in `prompt.md` is modular. To adapt for a different brand:
1. Replace the **BUSINESS DETAILS** section with your brand's info
2. Keep the **OUTPUT FORMAT** section unchanged
3. Adjust the **tone** field based on the brand personality
4. Run in Claude, ChatGPT, or Gemini
